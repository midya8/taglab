01 / DON'T HIDE THE LOSING METRIC

Better NLL.
More token errors.

Each family selects regularization by validation conditional NLL per token. The selected chain has lower test NLL, but its highest-probability sequence makes 66/164 token errors, versus 56/164 for the separately trained independent-label control. Probability quality and a decoding decision are different objectives.

Both models see the same eight observed features, including left and right context. The control is a trained three-class log-linear classifier with sequence scores fixed at zero. This is not an untrained or unigram strawman. The comparison describes these fitted models, penalties and finite fixture; it does not isolate transitions as a causal mechanism.

04 / WHERE THE NORMALIZER LIVES
The branch that cannot
give its mass back.
An original three-path control. Start at A or B with equal scores. A can only go to C; B can go to A or C. A final C receives weight w; final A receives weight 1. The same allowed paths and raw scores are normalized either globally or at each outgoing branch.
START
↙ A → C
↘ B → A or C
Local normalization always assigns total mass 1/2 to branch A, even as its only continuation loses raw weight. Global normalization changes that branch's mass. These are two fixed-score distributions, not fitted competing models or evidence that CRFs always outperform local classifiers. The trained independent-label control above is not this locally normalized branch model.


05 / THE LIMITS ARE PART OF THE MODEL
Nothing behind the curtain.
The fixture uses three persistent synthetic states and noisy symbols. All numeric inputs, labels, train/validation/test seeds, model candidates, parameters and selected IDs are retained. A trained independent-label model is selected by the same validation criterion. No real text, external benchmark, confidence calibration, deployment readiness, causal isolation or universal ranking is claimed.
Inference uses finite real scores and a fully connected chain. The separate exact normalization example has its own restricted path support; the inference API does not pretend large negative scores are exact forbidden transitions. Training and inference are dependency-free Python; this page is standalone scalar JavaScript.
Independent checks include sixty rational path-potential references, all 39 finite-difference derivatives, full feature-count enumeration, all 327 accepted optimization states and 12,753 scalar gradient entries. The complete test suite and installed reproduction are in the source.
