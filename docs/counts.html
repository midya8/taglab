02 / A GLOBAL EVENT CREATES DEPENDENCE

Right total.
Not independent positions.

Independent draws from the conditioned node marginals have the correct expected count but generally leave the exact-count event. Their Poisson-binomial count law is a separately calculated control, not a second fitted model. Per-position marginal decisions need not satisfy the event either. Only the complete constrained best path is required to do so.

Exact two-position control: start with independent fair A/B labels and require exactly one A. The two allowed paths AB and BA each have probability 1/2. Both node marginals are still [1/2, 1/2], but independent draws from them also produce AA and BB. Their event probability is only 1/2. This dependence comes from conditioning, even without transition scores.

04 / AN EVENT, NOT A BETTER MODEL
Same fit.
A narrower question.
The exact recurrence sums the finite allowed path set in log space. Computing all counts uses O(T² K²) time and O(T² K) stored messages. Conditional node and pair witnesses are reconstructed by matching prefix and suffix counts. This is established state augmentation, not a new method or a speed benchmark.
"Exact" describes the finite-state dynamic program, not real-number arithmetic. Binary64 roundoff and probability underflow remain possible. Maxima choose the lowest predecessor and then the lowest final label on an exact numerical tie. Near-tied representatives can differ between Python and JavaScript; score agreement is checked separately from path identity. These are synthetic numeric sequences with no semantic label meaning, new NLP validation or calibrated real-world confidence.
